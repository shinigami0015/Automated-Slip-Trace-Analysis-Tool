Automated Slip-Trace Analysis (ASTA) Tool - README

Welcome to the ASTA Tool!

## Running the Application
1. Simply double-click ASTA Tool.exe located inside the Software/ASTA_Application/ folder.
2. The application will automatically detect your MATLAB installation and start the engine in the background. You do not need to manually configure the MATLAB path in any text files.

## Important Note on MATLAB Connection
For the analysis engine to work properly, you must have the matlabengine Python package installed in your system's Python environment. If the tool opens but analysis is disabled, please open an Administrator Command Prompt and run the following command:
python -m pip install matlabengine
